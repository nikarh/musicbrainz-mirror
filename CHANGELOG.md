## [0.1.1] - 2026-11-08

### Features

- Import MusicBrainz database dumps into SQLite by @nikarh
- MusicBrainz web service lookups and browsing, in JSON by @nikarh
- Search by @nikarh
- XML responses by @nikarh
- The Cover Art Archive's API by @nikarh
- Serve, and keep the database up to date from MusicBrainz's full exports by @nikarh
- Serve from immutable memory-mapped files and tantivy instead of SQLite by @nikarh
- --compress-rows builds stores with compressed rows (15 GB instead of 19 GB) by @nikarh
- Log every request, received and answered (paired by id), with total and answering time, size and a summary of the answer by @nikarh
- Log the settings, store size and free space, every check for a new dump and the next one, verified downloads, archive reads and cleanup by @nikarh

### Fixes

- Name the slow statements of an import in its log by @nikarh
- Answer the nil UUID as an invalid MBID by @nikarh
- Answer as musicbrainz.org for work attributes, XML credits and genres, relationship order and related releases by @nikarh
- Never build a store into an existing directory by @nikarh

### Performance

- A store of 19 GB instead of 26 GB, search built in 6 minutes instead of 15 by @nikarh
